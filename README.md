# Discogs API App

A small app providing information from the discogs.com API.

# Features

- Get artist details (currently just the name)
- Get artist releases including ID
- Get release details

# Usage

You need to get an artist ID from discogs.com. With this ID, you can get the desired information using the app.
You can get a release ID from the release list inside the app or from discogs.com.

# Further Development

I developed this app to practise using the Discogs API. I'm going to develop a music database web app with Discogs API integration in the future. This app is just the base for this feature in a future project.
